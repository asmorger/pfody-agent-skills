# A conflict is recorded, not resolved

**Rule.** When two sources disagree, a newer *decision* supersedes an older statement — that is the
one resolution an agent may apply, and it cites the decision. Anything else is recorded: name both
sources and open a question. Never pick the more reasonable side.

**Why.** Which of two conflicting statements holds is almost never a question about the statements;
it is a question about who has authority and what has happened since. An agent has neither fact. A
conflict quietly resolved is the most expensive defect a PRD can carry, because it looks settled: the
losing stakeholder discovers it at demo, and the trail that would show when the choice was made does
not exist. Recorded, the same conflict costs one question.

**In the PRD.**
- Build the decision list from the newest source backwards, so a reversal is seen before the
  statement it reverses.
- Read long transcripts whole. A later meeting overturning an earlier one is the normal case, and a
  skimmed transcript is where that reversal hides
  ([`../practices/draft-a-prd.md`](../practices/draft-a-prd.md)).
- A reversal that a source states becomes a `DEC-xx` row with its reason and the option it rejected.
- Report what you were not allowed to read. An excluded source is exactly where a settling decision
  tends to live.

**Breaks when.** The agent arbitrates →
[`../anti-patterns/agent-picks-a-side.md`](../anti-patterns/agent-picks-a-side.md).
