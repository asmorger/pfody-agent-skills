# Silent mode downgrade

**Smell.** A story written in Mode C — from the request alone — handed over with no mention of it, and
no more Assumptions or Open Questions than a Mode A story would carry. Or a Mode A config whose source
paths have moved, producing a story that cites nothing and says nothing about why.

**Why it is wrong.** The mode is how much weight the story carries, and it is not recoverable from the
story's appearance: a Mode C story and a Mode A story are formatted identically. A reader who assumes
the project's corpus is behind it will estimate and build accordingly. The downgrade is also usually
fixable — a moved path, a config field nobody filled — so hiding it removes the one chance to fix the
thing that caused it.

**Instead.** Name the mode, say why you are in it, and let the Assumptions and Open Questions carry
the weight the sources cannot. A story explicitly built from one conversation with four open questions
is a good artefact; the same story presented as grounded is a liability. Where the downgrade came from
a path that no longer resolves, flag that and offer to update the config
([`../principles/mode-honesty.md`](../principles/mode-honesty.md),
[`../practices/determine-the-source-mode.md`](../practices/determine-the-source-mode.md)).
