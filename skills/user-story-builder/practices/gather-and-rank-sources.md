# Gather and rank sources

**When** the mode is settled and scope must be pulled from the sources. Step 2.

**Why.** Authoritative and supplemental sources carry different weight, and a story that cites the
wrong tier looks grounded while resting on an unreviewed note. The ranking is also what makes a
contradiction resolvable without guessing.

**Steps.**

1. **Pull scope only from the sources the config names.** A file nobody registered is not a source,
   however relevant it looks.
2. **Treat authoritative sources as the source of record.** Supplemental sources *inform* scope but
   are not citable as record — except under the discrepancy rule below
   ([`../patterns/source-tag.md`](../patterns/source-tag.md)).
3. **Use the scope guard where the config marks one present.** A SOW or an estimate bounds what this
   work includes. Where none is marked present, **do not reference one**.
4. **Apply the two-tier discrepancy protocol** when it is enabled and a supplemental source
   contradicts an authoritative one on a *material* point: state both positions, name the supplemental
   source explicitly, and add an Open Question. **Do not silently override the authoritative source**
   ([`../principles/pattern-matching-is-not-a-source.md`](../principles/pattern-matching-is-not-a-source.md)).
5. **Read the sources, not their titles.** A requirements document's section heading is not its
   content, and the behaviour you need is usually three paragraphs in.
6. **Check every id resolves** before citing it. A Mode A id pointing at nothing is worse than a Mode
   B name-and-section citation.
7. **Record what you could not read** — a moved path, a link you have no access to, a binary you
   cannot open. It goes to the user, not into an inference.

**Done when** scope came only from registered sources, authoritative and supplemental are kept
distinct, every id you intend to cite resolves, and any material discrepancy is stated with both
positions and an Open Question rather than resolved.
